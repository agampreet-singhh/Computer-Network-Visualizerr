🔌 Network Hardware Connecting Devices

Quick reference of essential networking equipment and their operating principles:

Device OSI Layer Forwarding Basis Broadcast Domain
Hub / Repeater Layer 1 (Physical) Floods all ports (Electrical signals) Single domain (Shared collision)
Switch / Bridge Layer 2 (Data Link) MAC Address Table (CAM table) Separate collision domains, single broadcast
Router Layer 3 (Network) IP Routing Table (Next Hop) Breaks broadcast domains
Gateway Layers 4 - 7 Protocol Translation (e.g. IPv4 to IPv6) Isolated application domains
Firewall Layers 3 - 7 Packet Filtering & State Inspection Security boundary filtering
