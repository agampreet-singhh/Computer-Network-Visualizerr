🔄 Distance Vector Routing Tables (RIP / Bellman-Ford)

Each router periodically shares its entire routing table with immediate neighbors using the Bellman-Ford equation: D_x(y) = min_v { c(x,v) + D_v(y) }.

📊 Routing Algorithm Comparison

Theoretical comparison between popular interior and exterior gateway routing protocols:

Feature Link-State (OSPF) Distance Vector (RIP)
Core Algorithm Dijkstra's Algorithm Bellman-Ford Algorithm
Knowledge Scope Complete network topology map Only distance and next hop via neighbors
Convergence Speed Fast (Instant updates on link change) Slow (Count-to-Infinity problem)
Metric Used Cost (Bandwidth / Delay) Hop Count (Max 15 hops)
Message Overhead Periodic Link State Advertisements (LSA) Periodic full routing table broadcasts (30s)
